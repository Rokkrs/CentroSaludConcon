# Centro Salud Concón

Propuesta de sitio web para un centro de salud especializado en neurodivergencia. El proyecto prioriza la reserva de evaluaciones, la presentación del equipo interdisciplinario, las especialidades clínicas y la vinculación con iniciativas internacionales.

## Tecnologías

- Astro
- HTML y CSS
- JavaScript

## Desarrollo local

Requiere Node.js 22.12 o superior.

```sh
npm install
npm run dev
```

El servidor de desarrollo se abrirá normalmente en `http://localhost:4321`.

## Comandos

```sh
npm run dev       # servidor de desarrollo
npm run build     # compilación para producción
npm run preview   # vista previa de la compilación
```

## Páginas

- `/`: landing principal del centro
- `/testimonios/`: propuestas de presentación de testimonios

## Estado

Prototipo visual destinado a evaluación y presentación al cliente. Los nombres, credenciales, cifras y datos de contacto deben validarse antes de una publicación definitiva.
